# Naija Spotlight (NaijaLift)

## Project info

This is the Naija Spotlight / NaijaLift application dashboard.

## Getting Started

### Prerequisites

- Node.js & npm installed

### Installation

1. Clone the repository
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the development server:
   ```sh
   npm run dev
   ```

## Technologies

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase (Auth & Database)

## Deployment

Build the project for production:

```sh
npm run build
```
