# NAIJALIFT - Discover Opportunities Across Nigeria

NAIJALIFT is your gateway to verified opportunities in Nigeria - scholarships, recruitment, grants, and events.

## Project info

Find verified government initiatives, scholarships, NGO grants, tech events, and career opportunities across all 36 Nigerian states.

## Getting Started

To get started with this project locally, follow these steps:

### Prerequisites

- Node.js & npm installed

### Installation

1. Clone the repository:
   ```sh
   git clone <YOUR_GIT_URL>
   ```

2. Navigate to the project directory:
   ```sh
   cd naija-spotlight
   ```

3. Install dependencies:
   ```sh
   npm install
   ```

4. Start the development server:
   ```sh
   npm run dev
   ```
